## 🚀 Featured Projects

### 🎬 Cine Perspective
**Interactive 3D Cinema Seat Preview System**

An interactive cinema seat-selection experience that generates real-time 3D screen previews based on the selected seat.

- Generates 3D screen previews for different seating positions.
- Ranks seats using viewing angle, distance, and visibility metrics.
- Combines interactive visualization with practical product functionality.

**Tech:** React · TypeScript · Three.js · React Three Fiber

### 🛡️ Safe Deal
**Escrow Payment Protection Web Application**

A full-stack escrow platform designed to protect transactions through controlled payment states and dispute safeguards.

- Implements a transaction lifecycle: `CREATED → FUNDED → DELIVERED → RELEASED`.
- Includes conflict-of-interest protection for dispute resolution.
- Uses server-side Razorpay HMAC-SHA256 signature verification.
- Implements JWT authentication using HTTP-only cookies, Zod validation, and an audit event timeline.

**Tech:** Next.js · TypeScript · Prisma · Razorpay

### 🌱 Plant Disease Detection
**Deep Learning Project | Image Classification Using PyTorch**

A computer vision application that accepts a leaf image and predicts whether the plant is healthy or has a particular disease.

- Uses a Convolutional Neural Network (CNN) and transfer learning for image classification.
- Processes leaf images using OpenCV or Pillow.
- Provides a FastAPI backend for image upload and prediction.
- Docker and AWS are part of the planned deployment stack if deployment is not yet complete.

**Tech:** Python · PyTorch · CNN · Transfer Learning · OpenCV/Pillow · FastAPI · Docker · AWS
